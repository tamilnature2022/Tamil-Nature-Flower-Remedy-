# TamilNatureShanmugam Android App — v0.2

## Implemented in this update
- 77 bilingual screening questions arranged across the 7 Bach emotional groups.
- Question-to-remedy mapping across the 38 Bach remedies.
- Category-wise scores, remedy-wise scores and Top 3 screening signals.
- Separate PSS-10 module with standard 0–4 frequency response options.
- Reverse scoring for PSS-10 items 4, 5, 7 and 8; total shown only when all 10 are answered.
- Report, print/save as PDF, CSV export, local records and optional Supabase account/cloud flow retained.

## Important validation note
The 77-question set is a draft adapted from the earlier prototype prompts and mapped to Bach categories/remedies. It is not a validated clinical or psychometric instrument. It requires content review, pilot testing, reliability/validity work and appropriate consent/privacy safeguards before research or clinical use. PSS-10 is a separate perceived-stress measure and is not diagnostic.

## Build
Open this folder in Android Studio and build the debug APK. A signed release APK / Play Store AAB requires your Android signing key and Play Console account.
